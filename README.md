FlatCAM: 2D Computer-Aided PCB Manufacturing
============================================

# Reloaded
This repo is a modified version of the original repo that can be found [here](https://bitbucket.org/jpcgt/flatcam/src/master/)
I have taken the time to update and port it to modern Qt as well as fix many bugs. It seems the original project is dead so therefore 
this would probably be the latest available release.

(c) 2014-2016 Juan Pablo Caram

FlatCAM is a program for preparing CNC jobs for making PCBs on a CNC router.
Among other things, it can take a Gerber file generated by your favorite PCB
 CAD program, and create G-Code for Isolation routing.

## Prebuilt releases

Pushing a `v*` tag builds and publishes two portable archives on GitHub Releases:

- `FlatCAM-macos-arm64.zip`: unzip and open `FlatCAM.app` on an Apple Silicon Mac.
- `FlatCAM-linux-x86_64.tar.gz`: extract and run `FlatCAM/FlatCAM` on x86_64 Linux. A desktop environment and its X11/Qt system libraries are required; builds target Ubuntu 22.04 or newer.

The macOS app is not signed or notarized, so macOS may require a manual Gatekeeper override. To test the bundles without publishing a release, run the **Build and release** workflow manually or open a pull request. To build locally, install `requirements.txt` and `pyinstaller`, then run `python -m PyInstaller FlatCAM.spec`.
